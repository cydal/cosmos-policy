# Policy scale-up QA: 800 -> 2,000 train episodes

Generated by `make_policy_scaleup_qa.py` (charts) and `viz_policy_modes.py`
(videos). Full write-up of the numbers behind these is in the conversation /
commit history; this folder is for looking at the result directly.

## Charts

- **`success_rate_comparison.png`** -- closed-loop success rate per split,
  before vs. after. The headline result: val 63%->82%, test 60%->90%, while
  train stayed flat (87%->86%) -- the train/val/test gap that was the whole
  problem essentially closed.
- **`loss_curves.png`** -- train/val loss, both runs overlaid. The "before" val
  loss (dashed blue) climbs sharply after epoch ~4; "after" (dashed orange)
  stays in a much flatter, noisier band -- healthier overfitting profile from
  more data + weight decay.
- **`val_accuracy_curve.png`** -- held-out per-frame accuracy, both runs.
- **`confusion_matrix_comparison.png`** -- per-primitive recall, side by side.
  `YAW_NEG` (0.34->0.69), `MOVE_Y_NEG` (0.50->0.71), and `GRIPPER_CLOSE`
  (0.77->0.96) are the biggest movers -- exactly the confusions predicted to
  improve from denser sampling of the existing camera-pose/position
  randomization, not a new mechanism.

## Videos (`modes/`, episode ep002150, test split, a real success)

- **`mode0_real.mp4`** -- the trained policy's actual closed-loop rollout in
  the real simulator: descends, grasps the cube, carries it onto the pad.
- **`mode1_parallel_imagination.mp4`** -- fine-tuned Cosmos re-imagining each
  16-step chunk of that same real trajectory, anchored fresh to a real frame
  each chunk. Tracks the real rollout closely.
- **`mode2_pure_imagination.mp4`** -- fully autoregressive: Cosmos imagining
  its own continuation with no real frames after the first. Drifts into
  distorted geometry by chunk 3-4, later than the equivalent demo with the
  previous (worse) policy checkpoint -- consistent with better real actions
  giving Cosmos an easier scene to track before compounding error takes over.
- **`comparison_strip.png`** -- all three, stacked, for a quick look without
  opening a video player.
